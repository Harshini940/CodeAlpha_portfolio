# Personal Portfolio

This is my personal portfolio website built using **HTML, CSS, and JavaScript**.  
It showcases my skills, projects, and basic information in a simple and responsive design.

## Features
- About Me section
- Skills section
- Projects showcase
- Contact information
- Responsive layout for all devices

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
Open the `index.html` file in any web browser to view the portfolio.
